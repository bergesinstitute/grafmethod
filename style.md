# Headings

Don't use italics in headings. Spanish words in headings stay unmarked (no quotation marks either). Only end them in period if the heading has at least two sentences.

    This is a one-sentence heading

    This is a two-sentence heading. Here is the second sentence.

# Dashes

Only use the short dash: -

Exception: in Spanish readings, model texts and conversations, keep the raya (—) for dialogue and for asides, following RAE rules. In explanations, use commas, a colon or parentheses instead, so the Spanish and the English line match. It is the same character as the English em dash, but a different punctuation sign.

# Markdown emphasis

Use * for italics, ** for bold. That said, avoid using bold for emphasis.

# AM, PM

We'll write them in lowercase and leave a space before: 9 am, 2 pm.

# Grammatical persons

No hyphen: first person singular, third person plural.

# Conversations

Character names go in normal case, never in all caps: María:, not MARÍA:.

Use the vocative comma, as RAE requires: Hola, Victoria. Gracias, Juan. Not Hola Victoria.

# Brand names

Coca-Cola, with a hyphen.

# Arrows

For transformations, use => with spaces around it: Yo compro una casa. => Yo la compro.

# Conjugation tables

After the conjugation table of a regular verb, add a separate code block with just the endings: o, as, a, amos, áis, an.

# Italics

Use them for foreign words, like *hablar.* Lo mismo si la oración es en español y estamos hablando del verbo *to sing.*
Use them as well when referring to a term itself, like the adverb *normally.*

# Letters

When we are talking about a letter, like A, we'll capitalize it without using italics.

# Escaping asterisks

If you need to display an actual asterisk at the end of an italized word, you'll have to precede it with a backslash: \*

# Square brackets

Never use square brackets: []. They create problems when rendering to other languages. The exception is 
footnotes (see below).

# Comments

Leave a space between the opening sign (>) and the first word.

# Apostrophe

Only use the vertical one (')

# Footnotes

Here is a footnote at the end of a sentence.[1] Here's one after a comma,[2] and here is one[3] in the middle of a sentence.

[1] First footnote

[2] Second

[3] Third

Each definition is a single line, placed right after the text it belongs to, before the next heading.

In a text divided into chapters, the notes may go at the end of the whole text.
