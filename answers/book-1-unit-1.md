# Answer key — Book 1, Unit 1

The unit 1 homework is a memorization exercise. The reference answers below are what you should be able to recite from memory.

## Ser, present tense

    yo soy

    tú eres

    él / ella / usted es

    nosotros / nosotras somos

    (vosotros / vosotras sois)

    ellos / ellas / ustedes son

## Estar, present tense

    yo estoy

    tú estás

    él / ella / usted está

    nosotros / nosotras estamos

    (vosotros / vosotras estáis)

    ellos / ellas / ustedes están

## Vocabulary checklist

- Personal pronouns: *yo, tú, él, ella, usted, nosotros/as, vosotros/as, ellos/as, ustedes.*
- Family members: *el padre, la madre, los padres, el hermano, la hermana, el hijo, la hija, el abuelo, la abuela, el nieto, la nieta, el tío, la tía, el primo, la prima, el sobrino, la sobrina, el perro, la perra, el gato, la gata, el esposo, la esposa.*
- Definite articles: *el, la, los, las.*
- Indefinite articles: *un, una, unos, unas.*
