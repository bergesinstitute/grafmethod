# Answer key — Book 2, Unit 10

The unit 10 homework is a memorization / review exercise. Below are the present-tense and *pretérito perfecto* conjugations you should know.

## Cantar (regular -ar)

**Presente**

    yo canto
    tú cantas
    él / ella / usted canta
    nosotros / nosotras cantamos
    (vosotros / vosotras cantáis)
    ellos / ellas / ustedes cantan

**Pretérito perfecto**

    yo canté
    tú cantaste
    él / ella / usted cantó
    nosotros / nosotras cantamos
    (vosotros / vosotras cantasteis)
    ellos / ellas / ustedes cantaron
